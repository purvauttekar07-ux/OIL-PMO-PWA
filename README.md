# 🛢️ OIL PMO – Field Progress Tracker

**Intelligent Data Capture & Schedule-Linking for Infrastructure Projects – Oil India Limited**

OIL PMO is a mobile-first Progressive Web App (PWA) that helps project teams capture progress data directly from the field and link it to project schedules, giving the PMO a clear, real-time view of how infrastructure work is moving.

🔗 **Live Demo:** https://oil-pmo-pwa.vercel.app/

## ✨ Features
- 📱 Installable PWA: works on phones like a native app
- 📝 Quick field progress data capture
- 🔗 Links captured progress to project schedules
- 📊 Gives the PMO a clear view of project status
- ⚡ Fast, lightweight, deployed on Vercel
